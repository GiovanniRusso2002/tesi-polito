\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis explores the migration of a legacy cloud platform toward a cloud-native architecture, using the Outsight Cloud platform as a case study. The existing system relied heavily on Airtable-based data management, manual operational processes, and infrastructure decisions that increasingly limited scalability, maintainability, and long-term sustainability.

The work focuses on how to modernize the platform while maintaining service continuity and reducing both technical and operational risks during the transition. Different solutions for identity management, hosting, storage, and data persistence are analyzed and compared. The proposed architecture is based on managed AWS services, Infrastructure as Code with Terraform, and a gradual migration from Airtable to PostgreSQL, supported by coexistence mechanisms designed to minimize disruption.

A key contribution of the thesis is a practical migration methodology that connects architectural decisions with measurable technical and economic criteria. The analysis considers aspects such as security, backward compatibility, observability, testing, deployment reliability, infrastructure costs, and operational overhead.

The thesis also presents the migration foundations already implemented within the project, including CI pipelines, smoke testing for dual backends, data replication and validation scripts, and separated infrastructure environments. The evaluation therefore focuses on the feasibility of the migration strategy, the quality of the target architecture, and the extent to which the proposed approach reduces migration risk.

The final result is a practical framework for supporting legacy-to-cloud-native migrations in real production environments. The work is intended for engineers and organizations looking to modernize existing systems through structured architectural evolution rather than simple technology replacement.
