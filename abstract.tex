\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis addresses a concrete engineering problem: how to migrate a legacy cloud platform to a cloud-native architecture while preserving service continuity and controlling both technical and economic risk. The case study is the Outsight Cloud platform, where legacy components relied heavily on Airtable-centric data management, ad-hoc operational workflows, and infrastructure choices that limited scalability, maintainability, and long-term cost efficiency.

We define the migration problem, identify constraints, and compare candidate solutions for identity management, application hosting, storage, and data persistence. The selected direction combines managed AWS services, Infrastructure as Code with Terraform, and incremental migration from Airtable to PostgreSQL, with explicit coexistence mechanisms to reduce transition risk.

A central contribution is a migration methodology that links architectural choices to measurable criteria. Technical criteria include security, backward compatibility, observability, testability, and deployment reliability. Economic criteria include recurring infrastructure cost drivers, operational overhead, and maintainability over time. Based on these criteria, we derive a target architecture and an incremental execution plan.

The thesis documents the implemented migration foundations and the validation strategy already available in project artifacts: dual-backend smoke testing, CI pipelines for consistency checks, data replication and validation scripts, and environment-separated infrastructure definitions. The evaluation is therefore focused on migration feasibility, design quality, and evidence of risk reduction.

The main outcome is a reusable, industry-grounded framework for planning and justifying legacy-to-cloud-native migration decisions. The results are intended for practitioners and organizations that need to modernize production systems through deliberate architectural design, not through one-off technology replacement.
