\chapter{Technologies and Tools}
\label{chap:technologies}

This chapter introduces the key technologies, frameworks, and tools employed in the modernization of Outsight's cloud infrastructure. We provide technical details necessary to understand the architectural decisions and implementation choices presented in subsequent chapters.

\section{Container Technologies}
\subsection{Docker}
Docker is the containerization platform used throughout this project. We discuss the container image structure, Dockerfile best practices, multi-stage builds, and security considerations such as rootless containers and minimal base images.

\subsection{Kubernetes}
Kubernetes orchestrates our containerized applications. We cover:
\begin{itemize}
    \item Core concepts: Pods, Services, Deployments, ConfigMaps, Secrets
    \item Networking model and Ingress controllers
    \item Storage abstractions: PersistentVolumes and PersistentVolumeClaims
    \item Role-Based Access Control (RBAC)
    \item Helm charts for package management
\end{itemize}

\section{Identity and Access Management}
\subsection{Keycloak}
Keycloak is the central IAM solution in our architecture. Key features leveraged include:
\begin{itemize}
    \item Realm configuration and client management
    \item Identity brokering and user federation
    \item Role-based and attribute-based access control
    \item Token management and refresh token rotation
    \item Admin API for programmatic configuration
\end{itemize}

\subsection{OpenID Connect (OIDC)}
We detail the OIDC authentication flows used in this work:
\begin{itemize}
    \item Authorization Code Flow with PKCE
    \item Token validation and signature verification
    \item Claims and scopes
    \item Session management and logout mechanisms
\end{itemize}

\subsection{JWT (JSON Web Tokens)}
JWT structure, signing algorithms (RS256, HS256), token expiration, and validation procedures are examined.

\section{Development and Deployment Tools}
\subsection{CI/CD Pipelines}
Continuous Integration and Continuous Deployment pipelines automate testing and deployment. Tools used include:
\begin{itemize}
    \item GitLab CI / GitHub Actions for pipeline automation
    \item Automated testing frameworks
    \item Container image scanning for vulnerabilities
\end{itemize}

\subsection{Infrastructure as Code}
We employ declarative configuration using:
\begin{itemize}
    \item Kubernetes manifests (YAML)
    \item Helm charts for templating and versioning
    \item Configuration synchronization tools
\end{itemize}

\section{Storage and Data Management}
\subsection{Object Storage}
We use MinIO or cloud-provider object storage (e.g., AWS S3, Azure Blob Storage) for file storage, discussing S3-compatible APIs, bucket policies, and encryption at rest.

\subsection{Databases}
Database technologies for user and configuration management include relational databases (PostgreSQL) and their integration with Keycloak.

\section{Monitoring and Observability}
\subsection{Logging}
Centralized logging using tools such as:
\begin{itemize}
    \item Elasticsearch, Logstash, Kibana (ELK stack)
    \item Fluentd or Fluent Bit for log aggregation
\end{itemize}

\subsection{Metrics and Monitoring}
Prometheus and Grafana for metrics collection and visualization. Key metrics include:
\begin{itemize}
    \item Service latency and throughput
    \item Resource utilization (CPU, memory, disk I/O)
    \item Authentication success/failure rates
\end{itemize}

\section{Security Tools}
\subsection{Vulnerability Scanning}
Container and dependency vulnerability scanning using tools like Trivy, Clair, or Snyk.

\subsection{Network Security}
Network policies in Kubernetes, TLS certificate management (Let's Encrypt, cert-manager), and API gateway security configurations.

\section{Tool Selection Rationale}
We justify the choice of each technology by comparing alternatives and explaining trade-offs in terms of:
\begin{itemize}
    \item Maturity and community support
    \item Integration capabilities with existing infrastructure
    \item Performance characteristics
    \item Security features
    \item Cost considerations
\end{itemize}
